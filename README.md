# ZERO PING：零延遲

原創電競選手生涯 TRPG。玩家會從地下海選一路前進到世界總決賽，在訓練、隊內事件與 BO3 賽事之間做選擇。

線上遊玩：<https://allenyuu.github.io/zero-ping/>

## 執行方式

這是無相依套件的靜態網頁遊戲。直接開啟 `index.html` 即可，或在此資料夾啟動任何靜態檔案伺服器。

例如：

```powershell
python -m http.server 8000
```

接著開啟 `http://127.0.0.1:8000/`。

## 內容

- 兩款原創競技項目：`CROWN//CORE` 與 `BREACH//ZERO`
- 四種選手原型、四種生涯目標
- 固定世界種子與可重現的 D20 結果
- 六季完整生涯、每季 3 顆 D6 自由能力分配、事件抉擇、BO3 比賽
- 生涯目標與最新紀錄置頂、7 項特殊任務與自由能力點獎勵
- 能力上限、健康、壓力、默契、士氣、粉絲與收入系統
- 自動存檔、12 項跨生涯成就、多重結局與評級
- 桌面與手機響應式介面

遊戲中的聯盟、隊伍、賽事、人物與競技遊戲皆為虛構設定。
