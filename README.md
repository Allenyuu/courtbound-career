# 籃途 COURTBOUND

目前版本：**v0.1**

一款從台灣國中出發的原創籃球生涯模擬器。玩家會從 13 歲一路玩到 35 歲；每個年齡都有自由規劃、人生支線、球隊日常、機會邀請與年度關鍵戰，完整生涯約 50–70 分鐘。

線上遊玩：<https://allenyuu.github.io/courtbound-career/>

## 原創核心：球場脈衝引擎

本作不套用既有生涯遊戲的固定事件樹。開局會隨機擲出 1–6 顆骰子供玩家自由配點，進入生涯後每次球場判定會即時計算：

- 六項球員能力：終結、投射、組織、防守、體能、球商
- 三條生涯脈衝：近期節奏、教練信任、身體負荷
- 球隊聯賽強度、賽季壓力、臨場變數與玩家累積的打法印記
- 球探值、聲望與冠軍數會一起決定你能收到哪些球隊邀請

## 遊戲內容

- 從 13 歲國中菜鳥一路走到 35 歲最後一舞，共 23 個年齡、每年 5 章
- 5 個場上位置，以及會隨選擇慢慢形成的打法印記
- 30 組隨機球員姓名，以及可分享、可重現的生涯種子碼
- 每組種子都藏有不同的初始能力、專長與成長速度，開局不公開答案
- 台、日、韓、中、美五國虛構學生與職業聯賽
- 每個年齡都有原創生活故事與 4 條人生支線，不只有場上劇情
- 體驗營、夏令營與測試只會先發邀請；玩家能參加、休息、自主訓練、找訓練師或處理生活
- 多國合約市場、球探評級、收入、冠軍與分歧生涯評級
- 自動存檔，以及包含學校／球隊路線、成就、名人堂評選的完整生涯卡與 PNG 卡
- 四種會直接改變成長、旅外門檻與球隊信任的生涯劇本：真實征途、五國遠征、一城王朝、逆風翻盤
- 1080 × 1920 詳細分享結算圖，收錄能力曲線、逐季球隊旅程、合約收入、代言、成就與名人堂評級
- 設定選單可重新生涯，或手動切換電腦版與手機版介面
- 支援桌面與手機

## 執行

這是無套件依賴的靜態網頁遊戲。使用任意靜態檔案伺服器開啟此資料夾即可。

所有球隊、聯賽、人物、規則與事件均為本作虛構原創設定。
