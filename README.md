# 電競選手模擬器

原創單人電競生涯 TRPG。玩家會在虛構競技項目 `ECHO//ARENA` 中，從凌晨公開海選一路走到世界決賽。完整一局約 30–45 分鐘。

線上遊玩：<https://allenyuu.github.io/zero-ping/>

## 遊戲內容

- 3 章、12 幕原創生涯劇情，每幕有 3 個不同抉擇
- 4 顆 D6 天賦骰，可自由分配給操作、讀局、協作與心態
- 4 種場上定位、3 種選手出身、3 個職業誓言
- D20 判定、能力修正、體力、壓力、隊伍默契、聲望與命運點
- 7 項特殊任務，完成後取得可自由分配的成長點
- 自動存檔、命運點重骰、分歧結局與生涯評級
- 自動產生 1080×1350 PNG 結算卡，支援下載及裝置原生分享
- 桌面與手機皆採固定單畫面；當幕三個選項不需上下捲動

## 執行方式

這是無外部相依套件的靜態網頁遊戲。直接開啟 `index.html`，或在本資料夾啟動靜態檔案伺服器：

```powershell
python -m http.server 8000
```

接著開啟 `http://127.0.0.1:8000/`。
