# 籃圖 COURT ATLAS

一款從台灣國中出發的原創籃球生涯模擬器。玩家會在每一季管理技術、節奏、信任與身體負荷，並依照表現收到台灣、日本、韓國、中國、美國的球隊邀請。

線上遊玩：<https://allenyuu.github.io/zero-ping/>

## 原創核心：球場脈衝引擎

本作不使用擲骰，也不套用既有生涯遊戲的固定事件樹。每次判定會即時計算：

- 六項球員能力：終結、投射、組織、防守、體能、球商
- 三條生涯脈衝：近期節奏、教練信任、身體負荷
- 球隊聯賽強度、賽季壓力、臨場變數與玩家累積的打法印記
- 球探值、聲望與冠軍履歷共同決定跨國合約門檻

## 遊戲內容

- 從 13 歲國中菜鳥一路走到 34 歲最後一舞，共 12 個生涯賽季
- 5 個位置、4 種球員原型、6 種可動態養成的打法印記
- 台、日、韓、中、美五國虛構學生與職業聯賽
- 每季包含個人訓練、更衣室抉擇與決勝回合
- 多國合約市場、球探評級、收入、冠軍與分歧生涯評級
- 自動存檔、球員卡、生涯時間軸與 PNG 結算卡
- 支援桌面與手機

## 執行

這是無套件依賴的靜態網頁遊戲。使用任意靜態檔案伺服器開啟此資料夾即可。

所有球隊、聯賽、人物、規則與事件均為本作虛構原創設定。
